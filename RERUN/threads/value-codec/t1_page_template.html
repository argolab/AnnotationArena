Does a narrower codec trade overfitting for capacity?

The learned linear codec writes a variable's value into the residual stream and reads its logits back out with a probe. Here it is confined to the last T of the stream's 80 dimensions, for T from 5 to 80, with and without the type centroids giving those dimensions up. Every arm is compared, run for run, against the hand-built dual stream.

How it was run

The arms

T = 80 is the full-width linear codec. Narrower arms project the value into the last T dimensions only, and the probe reads only those. In the reserved arms the type centroids and entity deviations are narrowed to 80 − T, so nothing else writes into the codec's dimensions at layer 0. T = 5, reserved has exactly the dual stream's geometry, with the hand-built copy replaced by a learned map.

Initialisation

Every encoder and probe weight is drawn N(0, 1), biases zero. Each coordinate of a width-T code therefore has unit scale, so a narrow code is quieter in total than a wide one (norm √T) and starts with smaller logits.

The dev split and the selected epoch

15% of observed training cells are hidden and scored every epoch (the mcar carve, split seed 7, identical in every arm). The selector is the shipped one: five-point centred smoothing, argmin, floor of 25 epochs. There is no refit, so every run trains on 85% of its observed training cells, in every arm alike.

K = 100 has no dev curve

At K = 100 the training partition is empty: every observed cell belongs to the test items, which transductive training conditions on. The carve finds nothing to hide, so those panels show training and test only, and their test loss is the mean of the last five checkpoints.

The test number

Corner log-loss: the test block's missing cells, scored with test items kept whole at evaluation chunk 500, the paper's population. At the dev-selected epoch it is interpolated on the 25-epoch checkpoint grid, as the early-stopping analysis did.

What is not here

K = 2000 and above, where the full-width codec previously matched the dual stream, are not in this sweep. Runs are 400 epochs at the final architecture (standard block, learned relational attention), not the 2000-epoch search the final run uses.
