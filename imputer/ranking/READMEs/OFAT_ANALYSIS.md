# OFAT Experiment Analysis: Commands, File Structure, and Visualization

## Core Commands in `ofat_small.sh`

When you run `bash ofat_small.sh`, it executes **6 sequential steps** for each experiment:

### Step 1: Generate Data
```bash
python stan/scripts/generate_data.py \
    --K-train 5 --K-test 5 --I 3 --J 6 --D <D> --C 5 \
    --observation-protocol <protocol> \
    --sigma-annotator <sigma_annotator> \
    --sigma-measurement <sigma_measurement> \
    --alpha-dirichlet <alpha_dirichlet> \
    --run-name <run_name> \
    --overwrite-existing-data
```
**Purpose**: Generates synthetic data using Stan data generation model.

### Step 2: Run Marformer (Neural Imputer)
```bash
python imputer/run_imputer.py \
    --data-dir OUTPUT/generated_data/<run_name> \
    --run-name <run_name>_marformer \
    --overwrite-existing-data \
    --epochs 70 --lr 1e-4 --masking-rate 0.50 \
    --masked-loss-weight 15 --observed-loss-weight 1 \
    --mask-augmentations 5 --early-stopping \
    --device cuda
```
**Purpose**: Trains the Marformer neural network to impute missing ratings/rankings.

### Step 3: Run Stan Inference (4 chains)
```bash
python stan/scripts/run_inference.py \
    --data-bundle OUTPUT/generated_data/<run_name>/data_bundle.json \
    --chains 4 \
    --iter-sampling 3000 --iter-warmup 1000 \
    --run-name <run_name>_stan4c \
    --overwrite-existing-data
```
**Purpose**: Runs MCMC inference with 4 chains.

### Step 4: Run Stan Inference (1 chain, long)
```bash
python stan/scripts/run_inference.py \
    --data-bundle OUTPUT/generated_data/<run_name>/data_bundle.json \
    --chains 1 --iter-sampling 3000 --iter-warmup 1000 \
    --run-name <run_name>_stan1c \
    --overwrite-existing-data
```
**Purpose**: Runs MCMC inference with 1 chain but longer sampling.

### Step 5: Evaluate Stan Predictions (both 4c and 1c versions)
```bash
python stan/scripts/evaluate_predictions.py \
    --data-bundle OUTPUT/generated_data/<run_name>/data_bundle.json \
    --mcmc-dir OUTPUT/domain_model/runs/<run_name>_stan4c \
    --run-name <run_name>_stan4c_eval \
    --overwrite-existing-data
```
**Purpose**: Evaluates Stan MCMC predictions against ground truth.

### Step 6: Generate Visualization Plots
```bash
python utils/visualize.py \
    --run-dir OUTPUT/IMPUTER/<run_name>_marformer \
    --stan-metrics OUTPUT/domain_model/eval/<run_name>_stan4c_eval/predictive_metrics.json
```
**Purpose**: Generates learning curves and calibration plots comparing Marformer and Stan.

## Resulting File Structure

```
OUTPUT/
├── generated_data/
│   └── ofat_small_<varied_param>_D<D>_sa<sa>_sm<sm>_kp<kp>_uc<uc>_<protocol>/
│       ├── configs.json              # Data generation configuration
│       └── data_bundle.json          # Generated data + ground truth
│
├── IMPUTER/
│   └── ofat_small_<...>_marformer/
│       ├── train_config.json         # Training hyperparameters
│       ├── model.pt                  # Trained model checkpoint
│       ├── train_training_history.json  # Training metrics per epoch (train set)
│       ├── test_training_history.json    # Training metrics per epoch (test set)
│       ├── test_metrics.json         # Final evaluation metrics
│       ├── predictives.json          # Model predictions on test set
│       └── plots/                    # Visualization plots (Step 6)
│           ├── train_loss.png
│           ├── train_accuracy.png
│           ├── test_loss.png
│           ├── test_accuracy.png
│           └── calibration_curve.png
│
└── domain_model/
    ├── runs/
    │   └── ofat_small_<...>_stan4c/  # or _stan1c
    │       ├── configs.json          # Inference configuration
    │       └── domain_model-*.csv     # MCMC samples (1 file for 1c, 4 files for 4c)
    │
    └── eval/
        └── ofat_small_<...>_stan4c_eval/  # or _stan1c_eval
            ├── evaluation_config.json
            ├── predictive_metrics.json    # Summary metrics (accuracy, MAE, log-likelihood, etc.)
            ├── rating_predictions.csv      # Per-sample rating predictions
            ├── rating_probabilities.csv   # Per-sample rating class probabilities
            └── pairwise_predictions.csv   # Per-sample pairwise predictions
```

## File Contents

### 1. `OUTPUT/generated_data/<run_name>/configs.json`
**Generated by**: `stan/scripts/generate_data.py` → `save_configs()`

**Contents**:
```json
{
  "datagen": {
    "K_train": 5, "K_test": 5, "I": 3, "J": 6, "D": 8, "C": 5,
    "sigma_annotator": 0.5, "sigma_measurement": 0.1,
    "alpha_dirichlet": 1.0, "temperature": 0.5,
    "observation_protocol": "tie_breaking",
    "seed": 42, ...
  }
}
```

### 2. `OUTPUT/generated_data/<run_name>/data_bundle.json`
**Generated by**: `stan/scripts/generate_data.py` → `save_bundle()`

**Contents**:
- `embeddings`: Ground truth item embeddings [K_train+K_test, D]
- `mean_preferences`: Ground truth mean annotator preferences [J, I]
- `annotator_preferences`: Ground truth per-annotator preferences [J, I]
- `rating_probs`: Ground truth rating probabilities
- `all_ratings`: All ratings (observed + missing)
- `observed_ratings`: Observed ratings (training data)
- `missing_ratings`: Missing ratings (test data)
- `observed_pairwise`: Observed pairwise rankings
- `missing_pairwise`: Missing pairwise rankings
- `stats`: Summary statistics (observation rates, counts, etc.)

### 3. `OUTPUT/IMPUTER/<run_name>_marformer/train_training_history.json`
**Generated by**: `imputer/run_imputer.py` (line 401)

**Structure**: Array of epoch entries
```json
[
  {
    "epoch": 0,
    "name": "train_all_evaluation",
    "total_loss": 2.17,
    "rating_loss": 2.17,
    "ranking_loss": 0.00003,
    "rating_accuracy": 0.74,
    "rating_rmse": 1.05,
    "ranking_accuracy": 1.0,
    "num_rating_evaluations": 90,
    "num_ranking_evaluations": 116,
    "observed_metrics": { ... },  # Metrics on observed data
    "missing_metrics": { ... },   # Metrics on missing data
    "masked_metrics": { ... }     # Metrics on masked data
  },
  ...
]
```

### 4. `OUTPUT/IMPUTER/<run_name>_marformer/test_training_history.json`
**Generated by**: `imputer/run_imputer.py` (line 395)

**Structure**: Same as `train_training_history.json` but for test set evaluations.

### 5. `OUTPUT/IMPUTER/<run_name>_marformer/test_metrics.json`
**Generated by**: `imputer/run_imputer.py` → `save_test_metrics()` (line 443)

**Contents**:
```json

```

### 6. `OUTPUT/IMPUTER/<run_name>_marformer/predictives.json`
**Generated by**: `imputer/run_imputer.py` → `_build_predictives()` (line 446)

**Structure**:
```json
{
  "predictions": [
    {
      "attribute": 0,
```

### 7. `OUTPUT/domain_model/runs/<run_name>_stan4c/domain_model-*.csv`
**Generated by**: `stan/scripts/run_inference.py` → `fit.save_csvfiles()` (line 189)

**Contents**: MCMC samples in CSV format. Contains:

## Existing Visualization Functions

Located in: `utils/visualize.py`

### 1. `load_run_data(run_dir: Path) -> Dict[str, Any]`
**Purpose**: Loads all JSON data from a Marformer run directory.

**Loads**:
- `test_training_history.json` → `data['test_history']`
- `train_training_history.json` → `data['train_history']`
- `predictives.json` → `data['predictives']`
- `test_metrics.json` → `data['test_metrics']`
- `train_config.json` → `data['config']`

### 2. `load_stan_metrics(stan_path: Optional[Path]) -> Optional[Dict[str, float]]`
**Purpose**: Loads Stan baseline metrics from `predictive_metrics.json` for comparison.

### 3. `plot_learning_curves_train(train_history: List[Dict], stan_metrics: Optional[Dict], output_dir: Path)`
**Purpose**: Plots training set learning curves.

**Generates**:
- `train_loss.png`: Rating loss over epochs (overall, observed, missing) + Stan baseline
- `train_accuracy.png`: Rating accuracy over epochs (overall, observed, missing) + Stan baseline
- `train_rmse.png`: Rating RMSE over epochs (overall, observed, missing) + Stan baseline
- `train_loss_accuracy.png`: Combined loss + accuracy subplots

### 4. `plot_learning_curves_test(test_history: List[Dict], stan_metrics: Optional[Dict], output_dir: Path)`
**Purpose**: Plots test set learning curves.

**Generates**:
- `test_loss.png`: Rating loss over epochs (overall, observed, missing) + Stan baseline
- `test_accuracy.png`: Rating accuracy over epochs (overall, observed, missing) + Stan baseline
- `test_rmse.png`: Rating RMSE over epochs (overall, observed, missing) + Stan baseline
- `test_loss_accuracy.png`: Combined loss + accuracy subplots

### 5. `plot_calibration(predictions: List[Dict], output_dir: Path)`
**Purpose**: Plots calibration analysis for missing rating predictions.

**Generates**:
- `calibration_curve.png`: Binned calibration curve (confidence vs accuracy) with perfect calibration line
- `confidence_histogram.png`: Histogram of confidence (max probability) for correct vs incorrect predictions

### 6. `plot_confidence_analysis(predictions: List[Dict], output_dir: Path)`
**Purpose**: Plots detailed confidence/uncertainty analysis.

**Generates**:
- `confidence_boxplot.png`: Box plot of confidence for correct vs incorrect predictions
- `entropy_histogram.png`: Histogram of prediction entropy (uncertainty) for correct vs incorrect
- `confidence_scatter.png`: Scatter plot of confidence by true class (colored by class, marked for incorrect)

### 7. `main()`
**Purpose**: CLI entry point that orchestrates all visualizations.

**Usage**:
```bash
python utils/visualize.py \
    --run-dir OUTPUT/IMPUTER/<run_name>_marformer \
    [--stan-metrics OUTPUT/domain_model/eval/<run_name>_stan4c_eval/predictive_metrics.json]
```

**Output**: Creates `plots/` subdirectory in the run directory with all generated plots.

## What's Missing for OFAT Visualization

The existing `visualize.py` focuses on **single-run** visualizations. For OFAT experiments, you'll need:

1. **Cross-experiment comparison plots**:
   - Sensitivity plots (metric vs hyperparameter value)
   - Heatmaps (2D hyperparameter sweeps)
   - Bar charts comparing methods (Marformer vs Stan 4c vs Stan 1c)

2. **Aggregation across OFAT runs**:
   - Load metrics from all 14 experiments
   - Extract hyperparameter values from run names or configs
   - Compare final metrics (accuracy, MAE, log-likelihood) across hyperparameter settings

3. **Method comparison**:
   - Marformer final metrics vs Stan 4c vs Stan 1c
   - Training time comparisons
   - Convergence speed comparisons

4. **Hyperparameter effect analysis**:
   - Effect of D (embedding dimension) on performance
   - Effect of σ_annotator, σ_measurement, κ on performance
   - Effect of protocol (SMAR vs Extended vs MCAR) on performance
   - Effect of use_concat_embedding on performance
