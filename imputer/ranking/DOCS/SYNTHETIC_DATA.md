# Synthetic Data: STAN-Generated Datasets

Synthetic data is generated by two probabilistic generative models implemented in Stan.
Both produce annotation matrices with known ground-truth structure, enabling controlled
evaluation of imputation quality.

**STAN model files:** `STAN/stan_models/`

---

## Generative Setup (Both Models)

Given I attributes, J annotators, K items, and C rating classes:

1. Each item `k` has a latent embedding `e_k ∈ R^D`.
2. Each (annotator, attribute) pair has a latent preference vector `V_ij ∈ R^D`.
3. The base score for rating `(i, j, k)` is `z_ijk = V_ij · e_k`.
4. An ordinal probit model converts `z_ijk` to a rating distribution:
   - Cut-points define C bins on the real line.
   - `P(c | z_ijk) = Φ(threshold_c − z_ijk/σ) − Φ(threshold_{c-1} − z_ijk/σ)`.
5. Observed ratings are sampled: `r_ijk ~ Categorical(P(· | z_ijk))`.
6. An observation mask is applied — not all (i, j, k) triples are observed.

The two models differ only in how `V_ij` is generated.

---

## Model 1: Normal (Spherical) — `normal_noise_dot_product`

**File:** `STAN/stan_models/normal_noise_dot_product_generation.stan`

**Annotator model:**
```
V_ij ~ N(v_i, σ_annotator² · I_D)    independently for each (i, j)
```

`v_i ∈ R^D` is the global mean preference for attribute `i`. Each annotator's preference for
attribute `i` is an independent Gaussian draw around the global mean.

**Properties:**
- Simple, symmetric annotator noise — all annotators are exchangeable given the global mean.
- No inter-attribute correlations in annotator behavior.
- Each (annotator, attribute) pair is independent of all others.
- Annotator deviation from `v_i` is isotropic.

**Data families:**
```
DATA/STAN/Normal_250_20_9_AnnotatorTest/   (250 items, 20 annotators, 9 attributes, AnnotatorTest splits)
DATA/STAN/Normal_650_20_9_ItemTest/        (650 items, 20 annotators, 9 attributes, ItemTest splits)
```

## Model 2: Factor (Factored Annotator) — `normal_noise_dot_product_generation`

**File:** `STAN/stan_models/normal_noise_dot_product_generation.stan` (with `use_factored_annotator=1`)
**Inference file:** `STAN/stan_models/normal_noise_dot_product_model.stan`

**Annotator model:**
```
V_ij = v_i + u_j · M_i
```

Where:
- `u_j ∈ R^{d_annotator}` is the annotator embedding (shared across all attributes for annotator `j`)
- `M_i ∈ R^{d_annotator × D}` is an attribute-specific transform matrix
- `V_ij` is fully determined (no noise) once `u_j` and `M_i` are fixed

**Properties:**
- Annotator style is captured by a low-dimensional embedding `u_j` shared across attributes.
- Annotator behavior across attributes is correlated through `u_j`.
- Given `u_j`, the model can predict how annotator `j` would rate on any attribute.
- Richer structure than Normal model — annotators are not exchangeable.

**Optional extensions (both models):**
- `derive_thresholds_from_annotator=1`: cut-points are derived from `u_j` via a learned linear
  map, making rating thresholds annotator-specific instead of shared.
- `enable_pairwise_rankings`: generates pairwise ranking observations in addition to ratings.

**Data families:**
```
DATA/STAN/Factor_250_20_9_AnnotatorTest/   (250 items, 20 annotators, 9 attributes, AnnotatorTest splits)
DATA/STAN/Factor_650_20_9_ItemTest/        (650 items, 20 annotators, 9 attributes, ItemTest splits)
```

## Split Types

### AnnotatorTest

**Held-out dimension:** annotators. Test annotators are entirely unseen during training.

All items are shared across train/val/test. Annotators are partitioned:
- Train: `J_train` annotators
- Val: `J_val` annotators
- Test: `J_test` annotators

The number suffix in the directory name is `J_test`:
```
Factor_250_20_9_AnnotatorTest_3    → J_test = 3
Factor_250_20_9_AnnotatorTest_6    → J_test = 6
Factor_250_20_9_AnnotatorTest_9    → J_test = 9
Factor_250_20_9_AnnotatorTest_12   → J_test = 12
Factor_250_20_9_AnnotatorTest_14   → J_test = 14
```

Generated by: `scripts/STAN/generate_data_annotatortest.sh`

### ItemTest

**Held-out dimension:** items. Test items are entirely unseen during training.

All annotators are shared. Items are partitioned:
- Train: `K_train` items
- Val: `K_val` items
- Test: `K_test` items

The number suffix is `K_test`:
```
Factor_650_20_9_ItemTest_10    → K_test = 10
Factor_650_20_9_ItemTest_50    → K_test = 50
Factor_650_20_9_ItemTest_100   → K_test = 100
Factor_650_20_9_ItemTest_250   → K_test = 250
Factor_650_20_9_ItemTest_500   → K_test = 500
```

Generated by: `scripts/STAN/generate_data_itemtest.sh`

## What the Bundle Contains

In addition to ratings, each STAN bundle includes:
- **`embeddings`**: item embedding matrix `[K, D]` from the generative model.
- **`annotator_embeddings`**: annotator embedding matrix `[J, d_annotator]` (Factor model only; zeros for Normal).
- **`train/val/test_posterior_rating_probs`**: STAN posterior predictive distributions for each
  (annotator, attribute, item) triple in each split — shape `[I×J_split, K, C]`. These are the
  oracle predictions used as baselines.
- **`rating_dist`**: for each observed rating, the one-hot distribution over classes
  (STAN data always has one-hot `rating_dist`; the `_is_one_hot` check skips encoding it,
  so `--llm-input-dist` is effectively a no-op on synthetic data).

**Important:** For ItemTest, test-instance ratings have **no `rating_dist`** in the bundle.
STAN has no posterior for entirely unseen test items. This is handled gracefully by the code:
`build_param` checks `if rating_dist is not None` before encoding.

## Data Generation Pipeline

```bash
# Generate data (from imputer/ranking)
bash scripts/STAN/generate_data_itemtest.sh      # generates Factor and Normal ItemTest bundles
bash scripts/STAN/generate_data_annotatortest.sh # generates Factor and Normal AnnotatorTest bundles

# Stan commands for specific families
bash scripts/STAN/stan_data_command_marformer.sh           # Normal ItemTest
bash scripts/STAN/stan_data_command_marformer_hard.sh      # Factor ItemTest
bash scripts/STAN/stan_data_command_marformer_annotator.sh # AnnotatorTest variants
```
